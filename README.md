# invoicepdfs-openapi

The OpenAPI specification for the [InvoicePDFs](https://invoicepdfs.com) API —
the source of truth for all client SDKs.

- `openapi.json` / `openapi.yaml` — the spec.
- Updated automatically from the API repo (`invoicepdfs`) via its **Sync SDK spec** workflow.
- On update, the language client repos (`invoicepdfs-<lang>`) are triggered to regenerate.
